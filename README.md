# منصّة وقّاد

منصّة تعليمية تفاعلية **مجانية** لطلاب المرحلة المتوسطة في المملكة العربية السعودية.
تشرح الدرس، وتُدرّب عليه، وتصحّح للطالب خطوة بخطوة مع بيان *لماذا*.

> **وقّاد**: يُقال «ذهنٌ وقّاد» للعقل الذكيّ سريع الفهم المتّقد.
> إعداد وإشراف المعلّم: **عمر بن عبدالله الهطلاني** — مجمع ابتدائية عمر بن عبدالعزيز ومتوسطة الأنصار.

---

## المبادئ

- **بلا حسابات ولا جمع بيانات** — تقدّم الطالب (النجوم/الإكمال) يُحفظ في متصفّح جهازه فقط (`localStorage`). مناسبٌ للقُصّر وآمنٌ لخصوصيتهم.
- **موقع ثابت بالكامل** — لا خادم ولا قاعدة بيانات، يُستضاف مجانًا على أي مضيف ثابت.
- **يعمل بلا إنترنت (PWA)** — بعد أول زيارة يعمل أوفلاين وقابل للتثبيت كتطبيق على الجوّال.
- **المحتوى بيانات** — الدروس ملفّات بيانات، تُضاف دروس جديدة بلا برمجة المحرّك.

## التصفّح

الصف (أول/ثاني/ثالث متوسط) ← الفصل (الأول/الثاني) ← المادة (العربية · الرياضيات · العلوم · الإنجليزية) ← الوحدة ← الدرس ← الأنشطة التفاعلية.

المُنجَز حاليًّا كاملًا: **الأول متوسط · الفصل الأول · الإنجليزية · الوحدة الأولى · Grammar — الفعل be** (ست مراحل + تحدٍّ نهائي بشهادة إتقان). بقيّة الدروس تظهر «قريبًا» حتى تُضاف بياناتها.

## التشغيل محليًّا

المنصّة تحتاج تقديمًا عبر خادم (بسبب عامل الخدمة والوحدات)، لا تُفتح مباشرة بنقر `index.html`.

```bash
# بايثون
python -m http.server 8000
# أو Node
npx serve .
```
ثم افتح `http://localhost:8000`.

## النشر المجانيّ

أي من الخيارات التالية مجانيّة تمامًا:

- **GitHub Pages**: ارفع المجلّد إلى مستودع، ثم Settings → Pages → Deploy from branch (`main` / root). الرابط: `https://<user>.github.io/<repo>/`.
- **Netlify**: اسحب مجلّد المشروع إلى [app.netlify.com/drop](https://app.netlify.com/drop) — يُنشر فورًا برابط مجانيّ.
- **Cloudflare Pages**: اربط المستودع، بلا أمر بناء، ومجلّد الإخراج هو الجذر.

الملفّ `.nojekyll` موجود ليخدم GitHub Pages كل الملفّات دون معالجة.

## إضافة درس جديد (بلا برمجة المحرّك)

1. أنشئ ملفًّا في `assets/data/` (مثال `en-sg1-u2.js`) يسجّل الدرس:
   ```js
   window.LESSONS = window.LESSONS || {};
   window.LESSONS['REF_ID'] = {
     id:'REF_ID', title:'عنوان الدرس', lang:'en', // lang:'en' يفعّل النطق والاتجاه LTR
     rule:{ tag:'القاعدة', title:'...', table:[['I','am'], ...], trick:'...' },
     stages:[
       { type:'choice', name:'...', hint:'...', qs:[ {p:'He ___ ...', o:['am','is','are'], a:1, w:'شرح لماذا', f:'الإجابة الصحيحة'} ] },
       // الأنواع المدعومة: choice | gap | error | order | mixed(final:true)
     ]
   };
   ```
2. أشِر إليه في `assets/data/curriculum.js` داخل الدرس المطلوب: `ref:'REF_ID'`.
3. أضِف وسم `<script>` للملفّ في `index.html` قبل `engine.js`.
4. حدّث قائمة `ASSETS` ورقم `CACHE` في `sw.js`.

### أنواع الأسئلة
| النوع | الشكل |
|---|---|
| `choice` / `gap` / `mixed` | `{ p, o:[...], a:الفهرس, w:'لماذا', f:'الصواب' }` — `gap` يضع فراغًا مكان `___` |
| `error` | `{ words:[...], bad:الفهرس, fix:'التصحيح', w, f }` |
| `order` | `{ sol:[...الترتيب الصحيح], w, f }` |

## البنية

```
index.html                 قشرة التطبيق والشاشات
assets/styles.css          منظومة الألوان (فاتح/داكن) والمكوّنات
assets/icons.js            أيقونات SVG مشتركة
assets/data/curriculum.js  الصفوف/الفصول/المواد/الوحدات/فهرس الدروس
assets/data/en-sg1-u1.js   بيانات درس الفعل be كاملًا
assets/engine.js           محرّك الأنشطة (خريطة المراحل + الأنواع + الشهادة)
assets/app.js              التنقّل والحالة والهوية وتسجيل PWA
manifest.webmanifest       بيان التطبيق
sw.js                      عامل الخدمة (العمل بلا إنترنت)
icons/icon.svg             أيقونة المنصّة
```

## تغيير الاسم أو الجهة
عدّل الكائن `window.BRAND` في أعلى `assets/app.js` فقط.
